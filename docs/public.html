大学・公共機関の方へ

稟議、相見積、請求書払い。発注の手続きに合わせて書類をご用意します。

発注の手続き

大学・公共機関の
発注手続きに合わせます

稟議や相見積に必要な書類を、お問い合わせの前からご用意しています。

ご依頼から納品まで

  1. 01問い合わせ決まっているのは日程と会場だけでかまいません
  2. 02見積書1営業日以内に、宛名入りのPDFでお送りします
  3. 03打ち合わせと会場確認オンラインで30分の打ち合わせと、会場のオンライン下見を行います
  4. 04本番当日、スタッフが会場に伺います
  5. 05納品と請求完了報告書、納品書、請求書をまとめてお送りします

書類と支払い

  • 見積書・納品書・請求書の3点を発行します
  • 請求書払い（後払い）に対応しています
  • インボイス登録番号：［T0000000000000］
  • 相見積のための見積依頼も歓迎します

仕様書のひな形を、そのまま使えます

配信業務の仕様書（A4 1枚、Word形式）と、見積書の見本をお送りします。他社への相見積にもそのままお使いください。

メールアドレスの形で入力してください

日程と会場だけで、見積書をお送りします

1営業日以内に、スタッフの役割と機材の内訳が入った見積書PDFをメールでお送りします。

見積書を受け取るプラン診断をする

8問でプラン診断

1 / 8

Q1 / 8登壇者は何人ですか

司会は含めません。パネルディスカッションの方も数えます

Q2 / 8会場に来る人は、何人くらいですか

おおよそでかまいません

Q3 / 8オンラインから登壇する人はいますか

遠隔地の講師がZoomなどで話す場合です

Q4 / 8会場の質問を、オンラインの視聴者にも届けたいですか

会場の声は、マイクを通さないと配信に入りません

Q5 / 8配信する時間は、どのくらいですか

休憩を含めた、配信の開始から終了まで

Q6 / 8録画を公開する予定や、外部の視聴者・来賓はありますか

どちらかに当てはまれば「ある」

Q7 / 8同じ日に頼みたいものはありますか

いくつでも選べます。なければ、そのまま「次へ」

Q8 / 8来年度からは、自分たちで配信したいですか

小さい会だけでも自分たちで、という場合も「はい」

お使いの環境では、結果をその場で表示できません。「次へ」を押すと、回答を持って見積のご依頼に進みます。
