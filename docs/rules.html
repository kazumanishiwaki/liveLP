8問でプランを診断する見積を依頼する

このページについて

白い地に、
ティールで道しるべを置く。

C案を元に、スマホを基本に組み直したサイトのルールです。色・影・目印は recruit.handy.school の仕組みを参考にしています。文字と余白は、幅390pxのスマホから1200pxのPCまで、段差なく大きくなります。

画面の組み方

スマホは1段、PCは左のレール＋1段

  • スマホを基本に書き、幅1024px以上で広げます
  • PCは左に幅200pxの固定レールを置きます。上からロゴ、メニュー（7項目まで。単語ではなく「何が書いてあるか」がわかる言葉で）、2つの行動（黄＝8問でプラン診断、珊瑚＝見積を依頼する。どちらもアイコンつき）、ページの切り替え。トップの中の項目には現在地が付きます。大学・公共機関の方へのページは、メニューの下にバナーで置きます
  • スマホでは上のバーとメニューの横並びが一緒に追従し、下部に追従ボタン（プラン診断／見積を依頼する）を置きます。メニューの中身はPCのレールと同じです
  • 本文はレールの右で1段。セクションの頭にタグ・見出し・リードを置き、その下に中身を置きます。左に見出しだけの列を作りません
  • トップに置くのは、メインビジュアル、費用の内訳、料金プラン、オプション、対応事例、よくある質問まで。当日の体制と流れ、配信支援ツール、内製化支援、発注の手続きは下層のページに分けます
  • プラン診断はページに埋め込まず、どのページのどこからでもボタンでモーダル（dialog）を開きます。スマホでは全画面、PCでは画面の中央に出ます。JSが動かないときは、ページの下に置いた診断へ移動します

文字の大きさと字間

1書体、1つの太さ

役割大きさ（px、スマホ → PC）見本
大見出し26 → 50カメラ5台はいりません。
セクション見出し26 → 44事例を公開しています
囲みの見出し18 → 28日程と会場だけ
小見出し18 → 26持ち込む機材の内訳
カードの題・質問16 → 20登壇者は何人ですか
リード14 → 18登壇者を迎え、進行を見守る。
本文14 → 16マイク音声を直接取り込みます。
補足12 → 14相見積にそのまま使えます

和文：Noto Sans JP（本文は Regular、見出しと強調は Medium。使う文字だけに絞って同梱）／英字・数字：Helvetica Neue。入力欄の文字はスマホでも16px。字間は大きさの2%、本文とリードの行送りは1.8、見出しは1.45。

色の役割

白の地に、主色のティール

  • #FFFFFF
    地：ページの背景（白）
  • #FAFAFA
    紙：白い地に置く箱、フォーム
  • #F8F6F3
    クリーム：帯、囲み
  • #F2FBFC
    淡いティール：帯
  • #4D4D4D
    文字：見出し・本文、フッター
  • #333333
    濃い文字：強調
  • #808080
    補足の文字（黒50%）
  • #E6E6E6
    罫線
  • #00B4C3
    ティール（主色）：目次の現在地・ボタン・診断・アイコン
  • #FF555F
    珊瑚：見積に進む・Q・番号
  • #FACA00
    黄：プラン診断・アイコン
  • #FFEB78
    マーカー：要点の下線
  • 主色はティール。目次の現在地、見出しのタグ、アイコンの四角、一覧の見出しの下線、手順の番号、診断で選んだ答え、プラン名の帯、そのほかの行動のボタンに使います
  • 珊瑚は「見積を依頼する」だけ：見積に進むボタン（どこにあっても同じ色）。ほかに、よくある質問のQと、送信後の流れの「いまここ」
  • 黄（#FACA00）は「プラン診断をはじめる」だけ：左レール、スマホの入口、下部の追従ボタン、メニューの中。ほかの場所では使いません。要点のマーカーは別の淡い黄（#FFEB78）で、本文の要点だけに引きます
  • 同じ意味のボタンは同じ色：黄＝プラン診断をはじめる、珊瑚＝見積を依頼する、ティール＝そのほかの行動（次へ、相談する、ひな形を受け取る）、線だけ＝資料や補助
  • 地は白。セクションの面はクリーム（#F8F6F3）とティールの淡い色（#F2FBFC）の2つだけで、どちらも参考サイトの半透明の色を白に重ねた値です
  • 差し色は小さな面にだけ使い、大きな面は白・クリーム・淡いティールのまま。ボタンやラベルの四角は参考サイトどおり、差し色の上に白い文字を乗せます
  • キーボードで操作しているときの枠は濃い文字色（#333333）。暗い面の上では白
  • 色・影・角丸・文字・動きの値は、design/karura-tokens.css の1つのファイルが元です。このサイトと、進行管理の「タイムキーパー」・質疑応答の「FAQ」（紹介ページ・管理画面・閲覧画面）が同じファイルを読むので、そこを直せば全体に反映されます

目印と影

目が滑らないための目印

長いページでも読む場所を見失わないよう、4つの目印を決まった場所にだけ置きます。

  • 要点のマーカー

    各セクションのリードで、いちばん伝えたい一文にだけ引きます。1つのセクションに1か所まで。文字の下半分を黄色（#FFEB78）にし、画面に入ったときに左から引かれます

  • 影は重ねない

    影が付くのは、いちばん外側の面だけ。影の付いた面の中に置くものは、線で区切ります。ボタンには影を付けません。強さは2つ：置いてあるもの（カード、白い箱、左レール）は 0 0 30px 黒8%、物として見せるもの（見積書の見本、暗い囲み）は 0 5px 40px 黒20%

  • 見出しのタグと、章の切れ目

    各章の頭に、目次と同じ言葉のタグ（白地にティールの線の丸い札）を付けます。スマホでは、章の頭に端から端までティールの線を引き、その線の上にタグを乗せて切れ目を示します。線画のアイコンはティールの角丸の四角（44px、角丸10px）に入れ、飾りなので読み上げからは外します

  • QとA

    よくある質問は珊瑚のQとティールのA。読む前に、問いと答えの区別がつくようにします

穴埋め（［ ］）はマーカーと見分けがつくよう、灰色の斜線にしています。

動きの決まり

動きは、減らせる

  • 押せるものの反応は 0.3秒、cubic-bezier(0.4, 0.4, 0, 1) にそろえます
  • 要点のマーカーは 0.8秒で引きます。幕や出現の動きは cubic-bezier(0.19, 1, 0.22, 1)
  • 読み込みの幕は、その回の最初の1回だけ。2回目からは出ません
  • カメラの自動切り替えには「切り替えを止める」ボタンをつけています
  • 端末で「視差効果を減らす」を選んでいる人には、幕・自動切り替え・出現の動き・マーカーの動きをすべて止めます（マーカーは最初から引いた状態）

使っているWeb標準

使っている Web 標準と、使えないときの形

基準は Baseline Widely available（主要ブラウザで30か月以上使えるもの）。それより新しい機能は、無くても見た目と操作が壊れない場所にだけ使っています。

機能Baseline（2026年11月）使っている場所使えないとき
<dialog>（showModal）Widelyスマホのメニュー。フォーカスを閉じ込め、Esc で閉じる— （JS が動かないときは、ヘッダーの「メニュー」がフッターのメニューへ移動）
<details open> / <summary>Widelyよくある質問。最初から開いておき、読み終えたものを閉じられる—
:has()Widelyカメラの切り替え（ラジオの選択で写真を出し分け）、診断の選択肢の色—
コンテナクエリ（size）Widely診断の選択肢を、箱の幅で1列／2列に。事例とスタッフの並び—
CSS のネスト、@layer、色の混色 color-mix()WidelyCSS の書き方—
:user-invalid と required / type=emailWidely入力の誤りを、触ったあとだけ赤く表示—
IntersectionObserverWidelyカメラの自動送りを、見えているときだけ動かす—
popoverNewly（2025-01）「?」で開く補足（マイク5本の理由など）未対応では、補足を本文の下に注記として表示し「?」を隠す
アンカー配置（anchor positioning）Newly（2026-01）補足を「?」の真上に出す未対応では、画面の中央に出す
@starting-style / transition-behaviorNewly（2024-08）メニューと補足が開くときの動き未対応では、動きなしで開く
スクロール連動アニメーションLimited見出しや写真が、スクロールに合わせて現れる未対応では、最初から表示
word-break: auto-phraseLimited見出しを文節で改行未対応では、通常の折り返し

「Widely」は主要ブラウザで30か月以上、「Newly」は主要ブラウザの最新版で使えるもの、「Limited」は一部のブラウザだけ。

8問でプラン診断

1 / 8

Q1 / 8登壇者は何人ですか

司会は含めません。パネルディスカッションの方も数えます

Q2 / 8会場に来る人は、何人くらいですか

おおよそでかまいません

Q3 / 8オンラインから登壇する人はいますか

遠隔地の講師がZoomなどで話す場合です

Q4 / 8会場の質問を、オンラインの視聴者にも届けたいですか

会場の声は、マイクを通さないと配信に入りません

Q5 / 8配信する時間は、どのくらいですか

休憩を含めた、配信の開始から終了まで

Q6 / 8録画を公開する予定や、学外の視聴者・来賓はありますか

どちらかに当てはまれば「ある」

Q7 / 8同じ日に頼みたいものはありますか

いくつでも選べます。なければ、そのまま「次へ」

Q8 / 8来年度からは、自分たちで配信したいですか

小さい会だけでも自分たちで、という場合も「はい」

お使いの環境では、結果をその場で表示できません。「次へ」を押すと、回答を持って見積のご依頼に進みます。
