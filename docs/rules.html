原則

白い地に、
ティールで道しるべを置く

サイトの組み方、色、パーツ、言葉の決まりをまとめています。迷ったときは、まず下の6つの原則に戻ります。

  1. 011段で組むスマホは1段、PC は左のレール＋1段。左に見出しだけの列を作らない
  2. 02色は意味で決める黄＝プラン診断、珊瑚＝見積を依頼する、ティール＝そのほか。同じ意味は同じ色
  3. 03押せるものだけを、押せる形にボタンと文字リンク以外は、枠や面でボタンに見せない
  4. 04影は2段だけで、重ねない影の付いた面の中は線で区切る。ボタンには付けない
  5. 05同じ意味のものは、同じ位置に金額や人数は縦位置をそろえ、同じ行動は同じ名前・同じ色
  6. 06相手に合わせた言葉は、その相手のページで大学・公共向けの言葉は特設ページだけ。ほかは一般的な言い方

画面の組み方

スマホは1段、
PCは左のレール＋1段

  • スマホを基本に書き、幅1024px以上で広げます
  • PC は左に幅200pxの固定レール。上からロゴ、メニュー、バナー（大学・公共機関の方へ）、2つの行動（プラン診断・見積を依頼する）、ページの切り替え
  • スマホは上のバーとメニューの横並びが一緒に追従し、画面の下に追従ボタン（プラン診断／見積を依頼する）。メニューの中身は PC のレールと同じ
  • トップの中の項目には現在地が付きます。読み進めた量のインジケータは付けません
  • トップに置くのは MV、強み、お悩み、サービス内訳、料金プラン、オプション、対応事例、よくある質問まで。当日の体制と流れ、配信支援ツール、内製化支援、発注の手続きは下層のページ
  • プラン診断はページに埋め込まず、ボタンでモーダルを開きます。スマホは全画面、PC は画面の中央。JS が動かないときはページの下の診断へ移動

余白・角丸・影

余白は画面の幅に
合わせて伸びる

場所トークン値（スマホ → PC）
ページの左右--pad16 → 80px
セクションの上下--sec / --sec-2 / --sec-3100 → 200px（大・中・小の3つ）
見出しと中身の間--gap-5628 → 56px
ブロックの間--gap-48 / --gap-6416 → 48px／40 → 64px
ボタンの高さ--btn-h48 → 60px
左レールの幅--rail200px
  • 角丸は4つ：入力欄・小さな箱 6〜8px、カード・アイコンの四角 10px、タグや札は丸（20px）、ボタンは 6px
  • 影は2段だけ：置いてあるもの（カード、白い箱、左レール）0 0 30px 黒8%、物として見せるもの（見積書の見本、暗い囲み）0 5px 40px 黒20%
  • 影の付いた面の中に置くものは、影ではなく線で区切ります。ボタンには影を付けません

    補足の「?」　.tip

    穴埋め　.ana

    まだ決まっていない値

    ［ ］で囲むと自動で灰色の斜線になる。マーカーと見分けるため黄色は使わない

    写真・図

言葉

同じことは、
同じ言葉で

  • 行動の名前はどこでも同じ：「プラン診断」「見積を依頼する」。見積フォームの送信だけ「見積書を受け取る」
  • メニューの名前：サービス内訳／料金プラン／対応事例／当日の体制と流れ／配信支援ツール／内製化支援（7つまで）
  • スタッフは「人」で数える（3人、4人）。金額は「25万円（税別）」
  • 大学・公共向けの言葉（大学、自治体、学会、公開講座、助成元など）は「大学・公共機関の方へ」だけで使う
  • トンチや言葉遊びはしない。何がどうなるかを素直に書く
  • まだ決まっていない値は［ ］で囲む（穴埋め）。推測で埋めない

動き

動きは、減らせる

  • 押せるものの反応は 0.3秒、cubic-bezier(0.4, 0.4, 0, 1)。幕や出現は cubic-bezier(0.19, 1, 0.22, 1)
  • ずっと動くのは、プラン診断のバッジの縁（24秒で1周）と、カメラの自動切り替え（止めるボタンつき）だけ
  • 要点のマーカーは画面に入ったときに 0.8秒で引きます。読み込みの幕は、その回の最初の1回だけ
  • 「視差効果を減らす」を選んでいる人には、幕・自動切り替え・バッジの回転・出現・マーカーの動きをすべて止めます

Web標準

使っている Web 標準と、
使えないときの形

新しい機能は、無くても壊れない場所にだけ使います。

機能Baseline（2026年11月）使っている場所使えないとき
<dialog>（showModal）Widelyスマホのメニュー、プラン診断。フォーカスを閉じ込め、Esc で閉じるメニューはフッターへ、診断はページの下へ移動するリンクになる
<details open> / <summary>Widelyよくある質問。最初から開いておき、読み終えたものを閉じられる—
:has()Widelyカメラの切り替え（ラジオの選択で写真を出し分け）、診断の選択肢の色—
コンテナクエリ（size）Widely診断の選択肢を、箱の幅で1列／2列に—
CSS のネスト、@layer、color-mix()WidelyCSS の書き方—
:user-invalid と required / type=emailWidely入力の誤りを、触ったあとだけ赤く表示—
IntersectionObserverWidelyカメラの自動送りを、見えているときだけ動かす。目次の現在地—
popoverNewly（2025-01）「?」で開く補足補足を本文の下に注記として表示し「?」を隠す
アンカー配置（anchor positioning）Newly（2026-01）補足を「?」の真上に出す画面の中央に出す
@starting-style / transition-behaviorNewly（2024-08）メニューと補足が開くときの動き動きなしで開く
スクロール連動アニメーションLimited見出しや写真が、スクロールに合わせて現れる最初から表示
word-break: auto-phraseLimited見出し、カードの題、ボタンの文字を文節で改行通常の折り返し

基準は Baseline Widely available（主要ブラウザで30か月以上使えるもの）。「Newly」は主要ブラウザの最新版で使えるもの、「Limited」は一部のブラウザだけ。新しい機能は、無くても見た目と操作が壊れない場所にだけ使います。

8問でプラン診断

1 / 8

Q1 / 8登壇者は何人ですか

司会は含めません。パネルディスカッションの方も数えます

Q2 / 8会場に来る人は、何人くらいですか

おおよそでかまいません

Q3 / 8オンラインから登壇する人はいますか

遠隔地の講師がZoomなどで話す場合です

Q4 / 8会場の質問を、オンラインの視聴者にも届けたいですか

会場の声は、マイクを通さないと配信に入りません

Q5 / 8配信する時間は、どのくらいですか

休憩を含めた、配信の開始から終了まで

Q6 / 8録画を公開する予定や、外部の視聴者・来賓はありますか

どちらかに当てはまれば「ある」

Q7 / 8同じ日に頼みたいものはありますか

いくつでも選べます。なければ、そのまま「次へ」

Q8 / 8来年度からは、自分たちで配信したいですか

小さい会だけでも自分たちで、という場合も「はい」

お使いの環境では、結果をその場で表示できません。「次へ」を押すと、回答を持って見積のご依頼に進みます。
