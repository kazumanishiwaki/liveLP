アセットの一覧

文字、色、余白、ボタン、パーツの見本と使い方です。見本は、サイトで使っている部品そのものを置いています。

  • 罫線　#E6E6E6
    一覧と表の区切り、箱の線

  • 青の上の文字は白。値の元は design/karura-tokens.css（ツールと共通）

余白・角丸・影

余白は幅に合わせて伸びる

場所トークン値（スマホ → PC）
ページの左右--pad16 → 80px
節の上（大・中・小）--sec / --sec-2 / --sec-3100 → 200px ／ 中 ／ 80 → 120px
見出しと中身の間--gap-5628 → 56px
ブロックの間--gap-48 / --gap-6416 → 48px ／ 40 → 64px
ボタンの高さ--btn-h48 → 60px（小は 44px）
  • ヒーロー（MV）のすぐ後の節は、上の余白を小（--sec-3）にする
  • 角丸：ボタン・入力欄 6px、カード・アイコンの四角 10px、コラム 28px、タグや札は丸
  • 影は大事なところだけ：比較表や主役のカード（0 0 30px 黒8%）、書類の見本と暗い囲み（0 5px 40px 黒20%）。ほかは細い線か面で区切る

  • 一覧を見る

    文字リンク　.tlink ＋ .go

    別の節やページへ移る。下線は引かず、右に背景なしのグレーの矢印

  • アイコンつき

    アイコンつき　.btn ＋ .bico

    ボタンの頭に線のアイコン。左に寄せ、矢印は右端

  • 押せるものだけを、ボタンの形にする。タグや札には枠や面を付けない
  • ボタンに影は付けない。右端に小さな矢印。スマホでは横いっぱい
  • 同じ意味の行動は、どこでも同じ色・同じ名前

見出しまわり

タグ、小見出し、札

  • よくあるお悩み

    タグ　.t-lab

    節の頭。枠も面も付けず、頭にティールの短い線。形は見直し中で、候補は見出しのタグの比較

  • タグ

    見出しは2行まで

    リードは1〜2文

    節の頭　sec()

    タグ → 見出し → リード の順に縦に積む。左に見出しだけの列は作らない

  • ケーススタディ

    小見出し　.sub

    節の中の区切り。ティールの小さな丸と濃い文字、右へ細い線を伸ばす

  • シンポジウム講演会

    札　.pill

    分類。線だけで、押せるものには使わない

入れ物

カード、吹き出し、囲み

    • カードの題

      アイコンと題を横に並べ、本文はアイコンの下まで広げる

    アイコンと文　.reason

    3つ並べるときは PC で3列。カードの題は1行に収まる字数（3列なら全角10字まで）

    • カードの題

      本文

      詳しく見る

    写真つきのカード　.reasons--card

    写真 → アイコンと題 → 本文 → 小さい淡い面のボタン。並べたときはボタンを下端にそろえる

    • お客さまの声は、吹き出しに入れます。

      話している人の肩書き

    吹き出し　.voice

    青のベタに白い文字。しっぽは人のアイコンを指す。並べたときは高さをそろえる

  • 白い箱
    クリーム
    暗い囲み

    白い箱・帯・暗い囲み　.boxw ／ .boxg ／ .boxd

    白い箱は細い線で、クリームは面だけで区切る。暗い囲みはページの終わりの行動に

  • コラム

    本筋から少し外れた読みもの

    コラム　.boxc

    ティールの太めの線と、大きな角丸で囲む。頭に「コラム」のタグ

  • バッジ

    バッジ　.badge

    黄の細かいギザギザ。縁だけがゆっくり回り、文字は回さない。ヒーローの縁に半分かけて置く

  • バナーの題ひとこと

    バナー　.banner

    特設ページへの入口。淡いティールの面に、左の帯と矢印

一覧と表

並べ方

    • 1行に1つ
    • 罫線で区切る

    行の一覧　.rows

    決まりや条件。番号は付けない

    1. 01相談順番に意味があるときだけ番号を付ける

    手順　.steps

    番号はティールの英数字

    • 含まれるもの
    • 確かめること

    チェックの一覧　.incl

    題と説明があるときは、題を太字にして改行

    • 項目の名前［金額］
    • 項目の名前［金額］

    名前と料金の行　.opt-rows

    左に名前、右に金額。説明は付けず、意味ごとに小見出しでまとめる

  • スタッフ3人
    カメラ3台

    表　.tbl ／ .cmp

    同じ意味の値は、同じ行・同じ縦位置にそろえる。スマホでは1行ずつ縦に積む（比較表は横スクロール）

  • 1 / 4

    スライダー　.cases ＋ .cases-count

    横にスクロール。右上に「1 / 4」で今の位置

補助

アイコン、マーカー、穴埋め

  • アイコン　.chipi ／ .bico

    四角に入れたもの（.chipi）は内容の目印、線だけのもの（.bico）はボタンの頭。飾りなので読み上げない

  • いちばん伝えたい一文にだけ引く

    要点のマーカー　.mk

    1つの節に1か所まで

  • マイク5本まで補足の文が、ここに出ます。

    補足の「?」　.tip

    読まなくても困らない補足。使えないブラウザでは本文の下に注記として出す

  • ［金額］

    穴埋め　.ana

    まだ決まっていない値。［ ］で囲むと自動で灰色の斜線になる

  • 画像の仮置き　img()

    写真・図は、本物が届くまで無地のグレー

動き

動きは、減らせる

  • 押せるものの反応は 0.3秒、cubic-bezier(0.4, 0.4, 0, 1)。幕や出現は cubic-bezier(0.19, 1, 0.22, 1)
  • ずっと動くのは、バッジの縁（24秒で1周）と、写真の自動切り替え（止めるボタンつき）だけ
  • 「視差効果を減らす」を選んでいる人には、自動の動きをすべて止める

8問でプラン診断

1 / 8

Q1 / 8登壇者は何人ですか

司会は含めません。パネルディスカッションの方も数えます

Q2 / 8会場に来る人は、何人くらいですか

おおよそでかまいません

Q3 / 8オンラインから登壇する人はいますか

遠隔地の講師がZoomなどで話す場合です

Q4 / 8会場の質問を、オンラインの視聴者にも届けたいですか

会場の声は、マイクを通さないと配信に入りません

Q5 / 8配信する時間は、どのくらいですか

休憩を含めた、配信の開始から終了まで

Q6 / 8録画を公開する予定や、外部の視聴者・来賓はありますか

どちらかに当てはまれば「ある」

Q7 / 8同じ日に頼みたいものはありますか

いくつでも選べます。なければ、そのまま「次へ」

Q8 / 8来年度からは、自分たちで配信したいですか

小さい会だけでも自分たちで、という場合も「はい」

お使いの環境では、結果をその場で表示できません。「次へ」を押すと、回答を持って見積のご依頼に進みます。
