当日の体制と流れ

誰が来て、何を持ち込み、当日どう動くか。見積書にも同じ内容を書きます。

当日の体制

スタッフ3人、
それぞれに持ち場があります

ディレクター・配信管理、カメラ・音声、2台目のカメラ。3つの持ち場に1人ずつで伺います。どれも本番中ずっと手を動かす仕事です。人数を増やして見積を大きくすることはしません。

  • ディレクター・配信管理

    進行の確認、画面の切り替え、配信の見守り。ご担当者との連絡もこの1人が受けます

    当日いる場所：配信卓（会場の音響卓の隣）

    当日いる場所：客席の横か後ろ

当日のタイムライン

13時に始まる会なら、
10時半に伺います

時刻は一例です。会場の入れる時間と開始の時刻に合わせて、打ち合わせのときに決めます。

配信の仕事の内訳

  1. 01準備 打ち合わせと下見オンラインで30分の打ち合わせ、会場のオンライン下見、配信先（Zoom・YouTubeなど）の設定
  2. 02設営 約2時間カメラ・マイク・回線を置いて、音と映像を確かめます
  3. 03本番 配信3時間まで撮影、音声の調整、画面の切り替え、配信の見守り
  4. 04撤収 約1時間機材を片づけます。録画データの納品はオプションです

当日の時刻の例

  1. 10:30搬入・設営カメラ・マイク・回線を置き、音と映像を確かめます
  2. 12:00リハーサル登壇者のPCをつなぎ、マイクの音量と、スライドの映り方を全員分確かめます
  3. 12:30開場・配信の待機待機画面で配信を始めておき、視聴者が入れるかを確かめます
  4. 13:00本番撮影、音声の調整、画面の切り替え、配信の見守り（3時間まで）
  5. 16:00撤収機材を片づけ、録画が残っているかを確かめます
  6. 17:00退館録画データの納品（オプション）は後日お送りします

当日の流れ

当日、ご担当者は配信に
かかりきりにならずに済みます

登壇者を迎え、進行を見守り、来賓に挨拶する。
配信の実務はスタッフにお任せください。

  • 01聞き取りやすい音

    会場のマイク音声を配信機材に直接取り込みます。会場にマイクがなければ5本まで持ち込みます。音が悪いと、研究まで低く見られます（Newman & Schwarz 2018）。

  • 02表情がわかるアップの映像

    客席の後ろから、話している人の表情を撮ります。来場者の視界をふさぎません。

  • 03見やすい画面の切り替え

    発表スライド、登壇者、会場全体の映像を状況に合わせて切り替えます。スライドの隅に登壇者の顔を出すこともできます。

  • 04万が一に備える予備機材

    録画機は2系統。予備回線（オプション）を付ければ、会場の回線が切れても配信を続けられます。

止まらないとは言いません。止まったときにどう戻すかを、事前にお渡しします

事前に「復旧手順書」を1枚お渡しします。何が止まったら、誰が、何分で、どう復旧するかを明記しています。

起きがちなトラブル

トラブルは当日起きますが、
原因は準備にあります

配信でよく起きる5つと、それぞれをどう防いでいるかです。

  • 01声が小さい、聞こえない

    会場の音響卓から音を直接取り込み、配信の音を音声担当がヘッドホンで聞き続けます

  • 02回線が切れる

    予備回線（オプション）を用意しておけば、切れてもすぐに切り替えます

  • 03画面の切り替えを間違える

    事前に進行表をいただき、誰が話すときにどのカメラを使うかを決めておきます

  • 04発表資料が映らない

    リハーサルで登壇者全員のPCをつないで確かめ、予備のPCにも資料を入れておきます

  • 05開始が遅れる

    開始の30分前から待機画面で配信を始め、視聴者が入れることを先に確かめます

事前チェックリストを、無料でお送りします

会場の回線、マイクの本数、登壇者のPCなど、配信の前に確かめることを1枚にまとめたPDFです。ご自身で配信する会にも、そのままお使いいただけます。

Q1 / 8登壇者は何人ですか

司会は含めません。パネルディスカッションの方も数えます

Q2 / 8会場に来る人は、何人くらいですか

おおよそでかまいません

Q3 / 8オンラインから登壇する人はいますか

遠隔地の講師がZoomなどで話す場合です

Q4 / 8会場の質問を、オンラインの視聴者にも届けたいですか

会場の声は、マイクを通さないと配信に入りません

Q5 / 8配信する時間は、どのくらいですか

休憩を含めた、配信の開始から終了まで

Q6 / 8録画を公開する予定や、外部の視聴者・来賓はありますか

どちらかに当てはまれば「ある」

Q7 / 8同じ日に頼みたいものはありますか

いくつでも選べます。なければ、そのまま「次へ」

Q8 / 8来年度からは、自分たちで配信したいですか

小さい会だけでも自分たちで、という場合も「はい」

お使いの環境では、結果をその場で表示できません。「次へ」を押すと、回答を持って見積のご依頼に進みます。
