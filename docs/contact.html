8問でプラン診断

1 / 8

Q1 / 8登壇者は何人ですか

司会は含めません。パネルディスカッションの方も数えます

Q2 / 8会場に来る人は、何人くらいですか

おおよそでかまいません

Q3 / 8オンラインから登壇する人はいますか

遠隔地の講師がZoomなどで話す場合です

Q4 / 8会場の質問を、オンラインの視聴者にも届けたいですか

会場の声は、マイクを通さないと配信に入りません

Q5 / 8配信する時間は、どのくらいですか

休憩を含めた、配信の開始から終了まで

Q6 / 8録画を公開する予定や、学外の視聴者・来賓はありますか

どちらかに当てはまれば「ある」

Q7 / 8同じ日に頼みたいものはありますか

いくつでも選べます。なければ、そのまま「次へ」

Q8 / 8来年度からは、自分たちで配信したいですか

小さい会だけでも自分たちで、という場合も「はい」

お使いの環境では、結果をその場で表示できません。「次へ」を押すと、回答を持って見積のご依頼に進みます。
