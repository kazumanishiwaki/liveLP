配信支援ツール

受付の名簿と、当日の質疑応答・進行も、配信と一緒に引き受けます。

受付とチケット

受付の名簿も、
配信と一緒に引き受けます

申込の受付、当日の入場、終了後の報告まで。
来場者とオンライン視聴者が、1つの名簿にまとまります。

  • 01QRコードで入場

    参加者のスマホに表示されたQRコードを、受付のスマホで読み取ります。専用の読み取り機はいりません。

  • 02タッチで入場

    受付に置いたタグにスマホをかざすか、受付でお伝えする4桁のコードを入れると、入場済みになります。受付に立つ人を減らせます。

  • 03紙の名簿も用意します

    同じ名簿を紙でもお持ちします。スマホを持っていない方や、会場の通信が不安定なときも、受付は止まりません。

  • 04終了後の報告を1枚で

    申込数、来場者数、オンライン視聴者数を1枚にまとめてお渡しします。上司や関係先への報告にそのまま使えます。

あらかじめ決めていること

  • どのプランにも含まれます。追加料金はかかりません（単体でご提供する場合の参考価格：［金額］）
  • チケットだけのご利用は、お受けしていません。配信をお任せいただく会でお使いいただけます
  • 参加無料・招待制の会が対象です。チケットの販売と決済は行いません
  • 来場300人までの会が対象です
  • 参加者の名簿は受付と報告のためだけに使い、会の終了から30日で自動的に削除します

申込をLINEログインにして、主催者のLINE公式アカウントの友だちを増やすこともできます（オプション）。

［QR］　読み取ると、デモのチケットが開きます　［デモ環境］

現場の道具

現場で使っている道具を、
いま試せます

お手元のスマホでお試しください。当日の質疑応答と進行がどう進むかを確認できます。

  • 質疑応答：FAQ

    会場とオンラインからの質問を1か所に集め、選んだ質問だけを登壇者の画面に表示します。

    ［QR］　コード ［000］　質問を送ると、上の画面に表示されます

  • 進行管理：タイムキーパー

    残り時間と合図を、登壇者とスタッフのスマホに表示します。進行の遅れを防ぎます。

    ［QR］　読み取ると、デモの進行表が開きます

  • 記録映像の作成：Movie Switcher

    3台のカメラの映像から、話している人に合わせて切り替えた記録映像と字幕を作ります。

  • 会場の確認：会場診断ツール

    会場でスマホやPCから開くだけで、回線の速さと安定さを測ります。ご依頼の前の確認に、無料でお使いいただけます。

    ［準備中］

これらの道具は、当日私たちが用意して操作します。ご自身で使えるようになりたい方には、内製化支援をご用意しています。　［穴埋め09：デモ環境］

日程と会場だけで、見積書をお送りします

1営業日以内に、スタッフの役割と機材の内訳が入った見積書PDFをメールでお送りします。

見積書を受け取るプラン診断をする

8問でプラン診断

1 / 8

Q1 / 8登壇者は何人ですか

司会は含めません。パネルディスカッションの方も数えます

Q2 / 8会場に来る人は、何人くらいですか

おおよそでかまいません

Q3 / 8オンラインから登壇する人はいますか

遠隔地の講師がZoomなどで話す場合です

Q4 / 8会場の質問を、オンラインの視聴者にも届けたいですか

会場の声は、マイクを通さないと配信に入りません

Q5 / 8配信する時間は、どのくらいですか

休憩を含めた、配信の開始から終了まで

Q6 / 8録画を公開する予定や、外部の視聴者・来賓はありますか

どちらかに当てはまれば「ある」

Q7 / 8同じ日に頼みたいものはありますか

いくつでも選べます。なければ、そのまま「次へ」

Q8 / 8来年度からは、自分たちで配信したいですか

小さい会だけでも自分たちで、という場合も「はい」

お使いの環境では、結果をその場で表示できません。「次へ」を押すと、回答を持って見積のご依頼に進みます。
