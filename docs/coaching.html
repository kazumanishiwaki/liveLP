来年度からは、
内製化したい

小さな会なら、お手持ちの機材で配信できます。どの会を自分たちで回すか、その基準づくりから一緒に始めます。

内製化の基準

自分たちで配信できる会と、
任せたほうがよい会

すべての会を内製にする必要はありません。会の大きさと、失敗したときの影響で分けます。

自分たちで配信できる会

  • 登壇者が1〜3人で、話す人があまり替わらない
  • カメラ1〜2台、マイク3本までで足りる
  • 会場の回線を事前に試せる
  • 配信の担当を2人置ける
  • うまくいかなくても、録画を後から公開すれば済む

私たちにお任せいただきたい会

  • パネルディスカッションがあり、カメラの切り替えが多い
  • オンラインから登壇する人がいる
  • 来賓や関係者が見る、やり直しのきかない会
  • 会場が広く、300人を超える
  • 担当者が1人しか置けない

どちらにも当てはまる会は、最初の打ち合わせで一緒に判断します。1年のうち小さな会はご自身で、大きな会だけ私たちに、という分け方もできます。

内製化支援

独り立ちするまで、
私たちが並走します

教えて終わりにはしません。最初は私たちが操作し、次は横で見守り、最後はオンラインで待機する。4つの段階で少しずつ手を離します。手順書とチェックリストが残るので、担当者が替わっても引き継げます。

  1. 01相談 ［3万円］オンライン60分。機材と接続の図、当日のチェックリストを作成します
  2. 02同行 ［代行＋3万円］私たちの配信現場に入り、実際の動きを横で見て覚えます
  3. 03並走 ［12万円］ご自身で配信を操作し、私たちは同じ現場で横に付きます。困ったらその場で代わります
  4. 04卒業 ［5万円］事前の機材点検と、当日のオンライン待機だけで見守ります
内製化について相談する

配信の前に確かめることをまとめた事前チェックリスト（無料）

まだ何も決まっていない方へ

15分のオンライン相談で、iPhoneで足りるかどうかから一緒にお話しします。決まっているのが日程だけでもかまいません。

見積書を受け取るプラン診断をする

8問でプラン診断

1 / 8

Q1 / 8登壇者は何人ですか

司会は含めません。パネルディスカッションの方も数えます

Q2 / 8会場に来る人は、何人くらいですか

おおよそでかまいません

Q3 / 8オンラインから登壇する人はいますか

遠隔地の講師がZoomなどで話す場合です

Q4 / 8会場の質問を、オンラインの視聴者にも届けたいですか

会場の声は、マイクを通さないと配信に入りません

Q5 / 8配信する時間は、どのくらいですか

休憩を含めた、配信の開始から終了まで

Q6 / 8録画を公開する予定や、外部の視聴者・来賓はありますか

どちらかに当てはまれば「ある」

Q7 / 8同じ日に頼みたいものはありますか

いくつでも選べます。なければ、そのまま「次へ」

Q8 / 8来年度からは、自分たちで配信したいですか

小さい会だけでも自分たちで、という場合も「はい」

お使いの環境では、結果をその場で表示できません。「次へ」を押すと、回答を持って見積のご依頼に進みます。
