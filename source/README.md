# カルラライブ サービスサイト

シンポジウム・講演会のハイブリッド配信代行「カルラライブ」のサイト一式です。

## 中身

| 場所 | 内容 |
| --- | --- |
| dist/ | 公開用のサイト。このフォルダをそのままサーバーに置けば動きます（16ページ、robots.txt、sitemap.xml つき） |
| preview/ | 確認用。index.html 1ファイルの中で全ページを切り替えます。公開には使いません |
| 穴埋めリスト.md | サイトの中で ［ ］ のまま残っている箇所の一覧。黄色く表示されます |
| build.py、pages_top.py、pages_sub.py、make.py | 書き出しのスクリプト。文言はすべてこの中にあります |
| src/ | スタイル（site.css）、動き（site.js）、共有用の画像（ogp.png、logo.png） |
| fonts-src/、img-src/ | 書体の元ファイルと、ダミー画像（P01〜P16、S01〜S03） |

## 作り直すとき

    pip install fonttools brotli
    python3 make.py          # A：新しいテイスト → dist/ と preview/
    python3 make.py rondo    # B：前のテイスト → dist-rondo/ と preview-rondo/

文言や設定を直したら、これで dist/ と preview/ と 穴埋めリスト.md が作り直されます。書体は、サイトで使っている文字だけに絞って書き出されます。

## 見た目は2種類あります

中身（文言、ページ、動く部品）は同じで、見た目だけが違います。違いは src/theme-rondo.css の1ファイルにまとまっています。

| | A：新しいテイスト | B：前のテイスト（rondomark.jp 寄り） |
| --- | --- | --- |
| 色 | 黒板の緑、朱、紙の白 | 明るいグレー、墨、グレージュ |
| 文字 | 見出しは太く、数字は Barlow Condensed | 太さは500だけ、字間を広く、数字は Helvetica |
| 組み方 | 帯ごとに全幅で切り替え | 左に見出し、右に内容の 5:7。帯は角丸で内側に入る |
| 動き | 配信画面の切り替えだけ | 見出しが1文字ずつ現れる、内容がふわっと出る、流れる英字 |
| ボタン | 朱 | 墨、右に矢印 |

どちらかに決めたら、使わないほうの dist は消してかまいません。

## 公開までに決めること・用意するもの

1. **ドメイン**：build.py の CFG['url'] を書き換える（canonical、OGP、構造化データ、sitemap に入ります）
2. **フォームの送信先**：build.py の CFG['form_endpoint'] と CFG['template_endpoint']。空のあいだは、フォームは何も送信しません。見積フォームは完了ページの見本に進むだけです
3. **電話番号**：決まったら、スマホ下部の「電話する」を tel: リンクに変える（いまは問い合わせページの電話番号欄に飛びます）
4. **穴埋めリスト.md の中身**：料金の追加分、スタッフの紹介、事例3件、取引先ロゴ、FAQ の答えなど
5. **写真**：img-src/ のダミー画像を、同じファイル名で差し替える。スタッフと事例の写真は実際のものを使う
6. **ダウンロード用のファイル**：仕様書のひな形（Word）、料金表と見積書見本（PDF）、当日のチェックリスト（PDF）。いまはボタンだけあり、押すと「まだ置いていません」と出ます
7. **オンライン相談の予約ページ**の URL
8. **記事3本の内容確認**：下書きです。現場を知っている人が確認して、書いた人の名前と公開日を入れる（構造化データの author と datePublished も make.py にあります）
9. **プライバシーポリシー**：下書きです。運営の実態に合わせて確認する

## プラン診断とサブナビ

- プラン診断（8問）がメインの導線です。トップではヒーローのすぐ下、/check/ に単独のページ、コーチングのページにも置いています。結果は「iPhoneで足ります」「コーチング：相談」「スタンダード」「まるごと」「大手の制作会社」の5つで、判定の中身は src/site.js の judge() にあります
- 結果から見積に進むと、診断の回答が問い合わせフォームの「気になっていること」欄に入った状態で始まります
- スマホでは、ヘッダーの下に現在地つきのサブナビが出ます（トップ、料金、ツールデモ、コーチング、大学・公共機関、プラン診断、記事）。スマホ下部の追従ボタンは「プラン診断」と「見積を依頼する」です

## デザインの考え方

- 色は、紙（明るいグレー）、墨、黒板の緑、朱の4つ。朱は「いま配信に乗っている画」を示すタリーランプの色で、押せるボタンにも同じ色を使っています
- いちばんの見せ場はトップの配信画面です。「カメラ1台だと」「カメラ3台だと」を切り替えると、見出しの意味がそのまま画面でわかります。写真がなくても成立するように、イラストで作っています
- 見積書と復旧手順書は、画像ではなく HTML で書類の形にしています。「見積書に内訳を全部書く」という約束を、実物の形で見せるためです
- 書体は Zen Kaku Gothic New、数字と機材ラベルは Barlow Condensed（どちらも SIL Open Font License）
- イントロのアニメーションは入れていません。見出しは最初から HTML にあり、JavaScript なしで読めます（SEO・AI検索 設計書の方針）
- 動きを減らす設定の端末では、配信画面の自動切り替えは止まります（手動では切り替えられます）
