Design rules

静かなグレーに、
必要なことだけを置く。

C案を元に、スマホを基本に組み直したサイトのルールです。文字と余白は、幅390pxのスマホから1200pxのPCまで、段差なく大きくなります。

Layout

スマホは1段、PCは左5：右7

  • スマホを基本に書き、幅1024px以上で2段に広げます
  • スマホではヘッダーの下に、現在地つきのサブナビ（トップ、お問い合わせ、デザインルール）と、下部の追従ボタン（プラン診断／見積を依頼する）を置きます
  • PCのヘッダーは、背景の色を反転させて重ねる固定ヘッダーのまま
  • プラン診断はトップの最初の画面に置き、PCでは見出しの右、スマホでは見出しのすぐ下です

Type

1書体、1つの太さ

役割大きさ（px、スマホ → PC）見本
大見出し26 → 50カメラ5台はいりません。
セクション見出し26 → 44事例を公開しています
囲みの見出し18 → 28日程と会場だけ
小見出し18 → 26持ち込む機材の内訳
カードの題・質問16 → 20登壇者は何人ですか
リード14 → 18登壇者を迎え、進行を見守る。
本文14 → 16マイク音声を直接取り込みます。
補足12 → 14相見積にそのまま使えます

和文：Zen Kaku Gothic New の Medium（使う文字だけに絞って同梱）／英字・数字：Helvetica Neue。入力欄の文字はスマホでも16px。

Color

灰色と砂色、赤1点

  • #F0F0F0
    地：ページの背景
  • #FBFBFB
    紙：フォーム、白い箱
  • #2C2C2E
    墨：文字、ボタン、暗い帯
  • #353637
    墨（淡）：質問の文字
  • #D7D5D0
    砂：帯、囲み、罫線
  • #7D7466
    砂（濃）：プラン名のバー
  • #6C6B68
    副文字：補足
  • #D7281E
    配信中の赤：配信中の印と、必須の印だけ

キーボードで操作しているときの枠だけは、見落とさないよう黄色（#F0B400）にしています。

Motion

動きは、減らせる

  • 曲線はすべて cubic-bezier(0.19, 1, 0.22, 1)
  • 読み込みの幕は、その回の最初の1回だけ。2回目からは出ません
  • カメラの自動切り替えには「切り替えを止める」ボタンをつけています
  • 端末で「視差効果を減らす」を選んでいる人には、幕・自動切り替え・流れる英字・出現の動きをすべて止めます

Platform

使っている Web 標準と、使えないときの形

基準は Baseline Widely available（主要ブラウザで30か月以上使えるもの）。それより新しい機能は、無くても見た目と操作が壊れない場所にだけ使っています。

機能Baseline（2026年11月）使っている場所使えないとき
<dialog>（showModal）Widelyスマホのメニュー。フォーカスを閉じ込め、Esc で閉じる— （JS が動かないときは、ヘッダーの「メニュー」がフッターのメニューへ移動）
<details> / <summary>Widelyよくある質問の開閉—
details[name]（1つだけ開く）Newly（2024-09）開いた質問以外を閉じる未対応では、複数同時に開けるだけ
:has()Widelyカメラの切り替え（ラジオの選択で写真を出し分け）、診断の選択肢の色—
コンテナクエリ（size）Widely診断の選択肢を、箱の幅で1列／2列に。事例とスタッフの並び—
CSS のネスト、@layer、色の混色 color-mix()WidelyCSS の書き方—
:user-invalid と required / type=emailWidely入力の誤りを、触ったあとだけ赤く表示—
IntersectionObserverWidelyカメラの自動送りを、見えているときだけ動かす—
popoverNewly（2025-01）「?」で開く補足（マイク5本の理由など）未対応では、補足を本文の下に注記として表示し「?」を隠す
アンカー配置（anchor positioning）Newly（2026-01）補足を「?」の真上に出す未対応では、画面の中央に出す
@starting-style / transition-behaviorNewly（2024-08）メニューと補足が開くときの動き未対応では、動きなしで開く
スクロール連動アニメーションLimited見出しや写真が、スクロールに合わせて現れる未対応では、最初から表示
word-break: auto-phraseLimited見出しを文節で改行未対応では、通常の折り返し

「Widely」は主要ブラウザで30か月以上、「Newly」は主要ブラウザの最新版で使えるもの、「Limited」は一部のブラウザだけ。
