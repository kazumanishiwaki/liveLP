このページについて

白い地に、
ティールで道しるべを置く。

C案を元に、スマホを基本に組み直したサイトのルールです。色・影・目印は recruit.handy.school の仕組みを参考にしています。文字と余白は、幅390pxのスマホから1200pxのPCまで、段差なく大きくなります。

画面の組み方

スマホは1段、PCは左のレール＋2段

  • スマホを基本に書き、幅1024px以上で広げます
  • PCは左に幅200pxの固定レールを置きます。上からロゴ、現在地つきの目次（単語ではなく「何が書いてあるか」がわかる言葉で）、2つの行動（黄＝8問でプラン診断、濃い珊瑚＝見積を依頼する）、ページの切り替え。右端の細い線が、ページを読み進めた量です
  • スマホでは上のバーと現在地つきのサブナビが一緒に追従し、下部に追従ボタン（プラン診断／見積を依頼する）を置きます。目次の中身はPCのレールと同じです
  • 本文はレールの右で、左5：右7の2段
  • プラン診断はトップの最初の画面に置きます。PCでは見出しの右でその場で答え、スマホでは見出しのすぐ下の黄色いボタンから全画面のモーダル（dialog）で開きます。サブナビや下部の「プラン診断」からも同じモーダルが開きます

文字の大きさと字間

1書体、1つの太さ

役割大きさ（px、スマホ → PC）見本
大見出し26 → 50カメラ5台はいりません。
セクション見出し26 → 44事例を公開しています
囲みの見出し18 → 28日程と会場だけ
小見出し18 → 26持ち込む機材の内訳
カードの題・質問16 → 20登壇者は何人ですか
リード14 → 18登壇者を迎え、進行を見守る。

和文：Zen Kaku Gothic New の Medium（使う文字だけに絞って同梱）／英字・数字：Helvetica Neue。入力欄の文字はスマホでも16px。字間は大きさの2%、本文とリードの行送りは1.8、見出しは1.45。

色の役割

白の地に、主色のティール

  • #FFFFFF
    地：ページの背景（白）
  • #FAFAFA
    紙：白い地に置く箱、フォーム
  • #F8F6F3
    クリーム：帯、囲み
  • #F2FBFC
    淡いティール：帯
  • #4D4D4D
    文字：見出し・本文、フッター
  • #333333
    濃い文字：強調
  • #808080
    補足の文字（黒50%）
  • #E6E6E6
    罫線
  • #00B4C3
    ティール（主色）：目次の現在地・ボタン・診断・アイコン
  • #FF555F
    珊瑚：見積に進む・Q・番号
  • #FACA00
    黄：プラン診断・アイコン
  • #FFEB78
    マーカー：要点の下線
  • 主色はティール。目次の現在地、見出しのタグ、アイコンの四角、一覧の見出しの下線、手順の番号、診断で選んだ答え、プラン名の帯、そのほかの行動のボタンに使います
  • 珊瑚は「見積を依頼する」だけ：見積に進むボタン（どこにあっても同じ色）。ほかに、よくある質問のQと、送信後の流れの「いまここ」
  • 黄（#FACA00）は「プラン診断をはじめる」だけ：左レール、スマホの入口、下部の追従ボタン、メニューの中。ほかの場所では使いません。要点のマーカーは別の淡い黄（#FFEB78）で、本文の要点だけに引きます
  • 同じ意味のボタンは同じ色：黄＝プラン診断をはじめる、珊瑚＝見積を依頼する、ティール＝そのほかの行動（次へ、相談する、ひな形を受け取る）、線だけ＝資料や補助
  • 地は白。セクションの面はクリーム（#F8F6F3）とティールの淡い色（#F2FBFC）の2つだけで、どちらも参考サイトの半透明の色を白に重ねた値です
  • 差し色は小さな面にだけ使い、大きな面は白・クリーム・淡いティールのまま。ボタンやラベルの四角は参考サイトどおり、差し色の上に白い文字を乗せます
  • キーボードで操作しているときの枠は濃い文字色（#333333）。暗い面の上では白
  • 色・影・角丸・文字・動きの値は、design/karura-tokens.css の1つのファイルが元です。このサイトと、進行管理ツール Que（紹介ページ・管理画面・閲覧画面）が同じファイルを読むので、そこを直せば全体に反映されます

目印と影

目が滑らないための目印

長いページでも読む場所を見失わないよう、4つの目印を決まった場所にだけ置きます。

  • 要点のマーカー

    各セクションのリードで、いちばん伝えたい一文にだけ引きます。1つのセクションに1か所まで。文字の下半分を黄色（#FFEB78）にし、画面に入ったときに左から引かれます

  • 影は重ねない

    影が付くのは、いちばん外側の面だけ。影の付いた面の中に置くものは、線で区切ります。ボタンには影を付けません。強さは2つ：置いてあるもの（カード、白い箱、左レール）は 0 0 30px 黒8%、物として見せるもの（見積書の見本、暗い囲み）は 0 5px 40px 黒20%

  • 見出しのタグと、章の切れ目

    各章の頭に、目次と同じ言葉のタグ（白地にティールの線の丸い札）を付けます。スマホでは、章の頭に端から端までティールの線を引き、その線の上にタグを乗せて切れ目を示します。線画のアイコンはティールの角丸の四角（44px、角丸10px）に入れ、飾りなので読み上げからは外します

  • QとA、○と—

    よくある質問は珊瑚のQとティールのA。お引き受けする会はティールの○、ほかの方法をおすすめする会は灰色の—で、読む前に種類がわかるようにします

穴埋め（［ ］）はマーカーと見分けがつくよう、灰色の斜線にしています。

動きの決まり

動きは、減らせる

  • 押せるものの反応は 0.3秒、cubic-bezier(0.4, 0.4, 0, 1) にそろえます
  • 要点のマーカーは 0.8秒で引きます。幕や出現の動きは cubic-bezier(0.19, 1, 0.22, 1)
  • 読み込みの幕は、その回の最初の1回だけ。2回目からは出ません
  • カメラの自動切り替えには「切り替えを止める」ボタンをつけています
  • 端末で「視差効果を減らす」を選んでいる人には、幕・自動切り替え・流れる英字・出現の動き・マーカーの動きをすべて止めます（マーカーは最初から引いた状態）

使っているWeb標準

使っている Web 標準と、使えないときの形

基準は Baseline Widely available（主要ブラウザで30か月以上使えるもの）。それより新しい機能は、無くても見た目と操作が壊れない場所にだけ使っています。
